# LinkedIn Project Entry

## Title

Mini Banking Data Warehouse — Oracle PL/SQL / APEX

## Description

Designed and implemented a compact banking-style Data Warehouse in Oracle that integrates ETL batch orchestration, metadata-driven data quality, SCD Type 2 customer history, dimensional modeling, transaction and balance facts, reconciliation, lineage/impact analysis and an APEX-ready monitoring layer.

The project demonstrates a full staging-to-DWH pipeline with operational logging, rejected-row handling, surrogate keys, star-schema reporting, business reconciliation and Oracle data-dictionary dependency traversal.

Technologies: Oracle Database, SQL, PL/SQL, Oracle APEX, ETL, Data Warehousing, SCD Type 2, Data Quality, Reconciliation, Data Lineage and Banking Data Concepts.
